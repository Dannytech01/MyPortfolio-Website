PROJECT 01 · GENERATIVE AI / RAG

Enterprise Knowledge Assistant

Architecture: Llama 3 8B · LoRA Fine-Tune · FAISS · FastAPI · Docker
Problem Statement

Internal teams at a mid-size SaaS company wasted ~12 hrs/week searching across fragmented docs, wikis, and Slack. Off-the-shelf chatbots hallucinated and couldn't cite sources, blocking adoption.

Engineering Approach
  • Designed chunking + embedding pipeline (bge-large) over 40k docs with metadata filters.
  • LoRA fine-tuned Llama 3 8B on 8k curated Q&A pairs for domain tone & citation format.
  • Built hybrid retrieval (dense FAISS + BM25) with reranking and source attribution.
  • Deployed via FastAPI + Docker on AWS ECS with autoscaling and Redis caching.

PROJECT 02 · COMPUTER VISION

Real-Time Defect Detection on Assembly Line

Architecture: YOLOv8 · TensorRT · Edge GPU · ONNX · Streamlit Dashboard
Problem Statement

Manual QC on a high-throughput line missed ~6% of surface defects, causing downstream rework and customer returns. Inspection had to run at 30+ FPS on edge hardware with <50ms latency.

Engineering Approach
  • Curated & labeled 18k images across 14 defect classes; handled class imbalance via focal loss + augmentation.
  • Trained YOLOv8m, then exported to ONNX and optimized with TensorRT (FP16/INT8).
  • Built async capture→inference→alert pipeline with graceful degradation & offline buffering.
  • Delivered operator dashboard for live monitoring, defect heatmaps, and weekly model drift reports.

PROJECT 03 · MLOPS / OPTIMIZATION

Inference Cost & Latency Optimization Platform

Architecture: vLLM · Quantization · Batching · MLflow · Kubernetes · Prometheus
Problem Statement

An LLM product's inference bill grew 3x in a quarter while p95 latency degraded under load. Need to cut cost per token and stabilize tail latency without quality regression.

Engineering Approach
  • Profiled bottlenecks; replaced naive serving with vLLM (PagedAttention, continuous batching).
  • Applied AWQ 4-bit quantization + speculative decoding; validated quality with eval harness.
  • Implemented dynamic batching, KV-cache reuse, and request prioritization by SLA tier.
  • Added Prometheus/Grafana dashboards + autoscaling HPA on GPU utilization.
